# ⚜️ Козацька рада: Зрада в Чигирині — онлайн

Соціальна дедукція (мафія) у козацькому сетингу, 8–14 гравців (основний склад — 14).
Сервер сам веде гру: роздає ролі, проводить ніч, рахує голоси і перемогу.
Гравці говорять наживо, а телефон — таємна картка ролі, нічні дії та голосування.

## Запуск на ноутбуці
Подвійний клік на **start.bat** (або `python server.py`). У вікні з'являться адреси:
- `http://localhost:8000` — на самому ноутбуці;
- `http://192.168.x.x:8000` — для телефонів у тій самій Wi-Fi.

## Як грати
1. Господар відкриває сайт → «Скликати нову раду» → отримує код із 4 літер.
2. Гравці відкривають той самий сайт з телефонів → ім'я + код → «Приєднатися».
3. На проектор/ТВ: `/screen?room=КОД` — коло ради, таймер, оголошення, голосування (ролі не видно).
   Унизу праворуч — «🔈 Увімкнути звук ради» (браузер дозволяє звук лише після натискання) і гучність.
   Звуки синтезуються в браузері: дзвін ради, нічний гонг, вітер і цвіркуни, дріб при висуненні,
   стук печаток при голосуванні, литаври на вироку, цокання останніх 5 с, сурми перемоги / вогонь поразки.
4. Господар тисне «Почати раду». ⏭ угорі — пропустити фазу.
5. «🤖 Додати ботів» — заповнити до 14 для тренування самому.

## Грати через інтернет (безкоштовно)
**Варіант А — ноутбук + Cloudflare Tunnel** (ноутбук має бути ввімкнений):
1. Завантаж `cloudflared` для Windows з офіційного сайту Cloudflare.
2. Запусти гру (`start.bat`), потім у другому вікні:
   `cloudflared tunnel --url http://localhost:8000`
3. Скопіюй посилання `https://….trycloudflare.com` і розішли гравцям.

**Варіант Б — Render.com** (працює без ноутбука):
1. Заклади папку `kozacka_rada` у репозиторій на GitHub.
2. На render.com → New → Blueprint → вибери репозиторій (файл `render.yaml` уже готовий).
3. Безкоштовний сервер засинає після 15 хв простою — перше відкриття ~30–50 с.

## Структура
- `game.py` — правила і перебіг партії (без мережі).
- `server.py` — веб-сервер + WebSocket.
- `static/` — інтерфейс (HTML/CSS/JS, без збірки).
- `tests/sim.py` — прогін сотень партій ботами: `python tests/sim.py`.
- `tests/test_night.py` — нічні ролі (Писар, Знахар, Джура, Перевертень, Характерник).
- `tests/test_vote.py` — голосування за правилами мафії.

## Правила (коротко)
Склад для 14: 3 Зрадники, Перевертень, Характерник, Знахар, Джура, Писар, 6 Старшин.
Голосування — як у класичній мафії: вдень кожен може висунути одного кандидата, кандидати
по черзі захищаються, потім кожен голосує за одного (або «нікого»). Хто набрав найбільше — вибуває
одразу, без порогу 50%+1. Нічия → ніхто. Перевірка правил: `python tests/test_vote.py`.
Писар щоночі або перевіряє (👍/👎), або арештовує — раз за гру і лише того, хто вже показав 👍.
Гра починається з ночі. Порядок ночі: Зрадники → Перевертень → Характерник → Джура → Знахар → Писар.
Де довідник v7 мовчить, діють правила класичної мафії: Знахар захищає від будь-якого удару
(і від Характерника), заблокований Характерник не витрачає удар, ролі загиблих уночі не розкриваються.
